# FreeNet Hub — انتشار عمومی فعلی Windows R53 و Linux R21

**مرجع نصب پایدار (بررسی‌شده در ۱۷ اکتبر ۲۰۲۶):** [Free Net Hub 4.3.9 R53 در GitHub Releases](https://github.com/GOD13emad/FreeNetHub/releases/tag/v4.3.9-r53-windows-stable)

فقط دارایی‌های این انتشار با نام و SHA-256 زیر نسخهٔ عمومی پایدار هستند. کد شاخهٔ `main`، پیش‌نمایش‌ها و نسخه‌های نصب‌شدهٔ آزمایشی مالک، لزوماً با این دارایی‌ها یکسان نیستند.

## Windows R53 — نصب‌کنندهٔ عمومی

- فایل: `FreeNetHub_4.3.9_R53_Setup.exe`
- SHA-256: `34A1A45383F8E35F7D23CBD12A76440D063CE43D49E3A5CC23A3518F947353A2`
- نسخه: `4.3.9-r53-inno-root-guard`
- نصب/ارتقای درجا فقط در وضعیت قطع اتصال برنامه و با هویت نصب سازگار انجام می‌شود. اگر مسیر برنامه یا ثبت Uninstall تعارض داشته باشد، نصب‌کننده باید بدون تخریب داده‌ها متوقف شود.
- نصب‌کننده **امضای دیجیتال معتبر ناشر ندارد**. برای نصب، SmartScreen یا دیگر حفاظت‌های Windows را غیرفعال نکنید.

## Linux R21 — بستهٔ عمومی فعلی

- فایل: `FreeNetHub_4.2.0_Linux_R21.zip`
- SHA-256: `82305E1A15684662B7711B53A84522122C6A11D618366314D9DD297B3A7FEC1A`
- نسخه: `4.2.0-linux.21-r54`
- نسخهٔ R21 روی لپ‌تاپ مالک با رابط GTK و مسیر محدود CFON نصب و آزمایش شده است؛ صحت فایل‌های نصب و حفظ تنظیمات در ارتقای R20→R21 بررسی شده‌اند.
- بستهٔ R20 در همین انتشار فقط برای بازگشت/مقایسهٔ نسخهٔ قبلی حفظ شده است؛ **R20 نسخهٔ جاری Linux نیست**. ارتقا هنگام اتصال فعال باید به‌صورت ایمن متوقف شود.

## نسخه‌های توسعه و پیش‌نمایش (نه انتشار پایدار)

- Windows R54 در بخش Pre-release موجود است و نباید با نصب‌کنندهٔ پایدار R53 اشتباه شود.
- Windows `4.3.13 R57` روی یک دستگاه مالک نصب و در محدودهٔ CFON/تونل انتخابی آزمایش شده است؛ **این موضوع به معنی انتشار پایدار عمومی R57 نیست**.
- Linux `4.2.0-linux.24-r57` یک بستهٔ آزمایشی CI است. نصب تازه، ارتقا و بازگشت نسخه در `HOME` ایزوله روی Ubuntu واقعی آزمایش شده‌اند، اما R24 هنوز جایگزین نصب فعال R21 مالک نشده است.
- ابزار اختیاری و برگشت‌پذیر رسیدگی به دو فایل باقی‌ماندهٔ R24 پس از بازگشت به R21 در [راهنمای پاک‌سازی rollback](docs/LINUX_ROLLBACK_RESIDUE.md) توضیح داده شده است. این ابزار داخل بستهٔ عمومی قدیمی R21 نیست و به‌صورت خودکار اجرا نمی‌شود.

## امکانات و حدود اعتبار

رابط برنامه دارای Dashboard، Methods، Nodes، Tools و Settings است. روش‌های مرورگر/پراکسی می‌توانند شامل AUTO، Node Pool، WARP، GOOL، CFON، Tor/Bridges، Custom و Direct باشند. انتخاب روش، تست سلامت/سرعت نود، بروزرسانی نسخه و تونل انتخابی برحسب سیستم‌عامل و نسخهٔ نصب‌شده تفاوت دارند. **وجود گزینه در رابط کاربری، اثبات عملکرد آن روی همهٔ دستگاه‌ها نیست.**

تونل CFON که در شواهد بالا قبول شده، عمدتاً برای مرورگر/پراکسی محدود است. **تونل کل سیستم، نبود نشت DNS/UDP، Console فیزیکی، عملکرد واقعی Android/iOS روی سخت‌افزار، و دسترسی احراز هویت‌شدهٔ Google Cloud هنوز پذیرش نهایی ندارند.** عبور درخواست عمومی از HTTP 403 به HTTP 302 یا 200 به‌تنهایی اثبات دسترسی حساب کاربری نیست. همچنین هیچ برنامه‌ای در صورت قطع همهٔ مسیرهای بالادستی نمی‌تواند اینترنت را تضمین کند.

مسیرهای نیازمند Administrator/root یا پذیرش شرایط Cloudflare WARP فقط با مجوز معتبر سیستم‌عامل و اقدام آگاهانهٔ مالک اجرا می‌شوند؛ نباید برای عبور از حفاظ‌های سیستم روش‌های ناامن به‌کار برد.
