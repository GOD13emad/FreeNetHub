FreeNet Hub 4.1.1

Windows standalone shell / مرکز واحد مرورگر / ۲۰ محصول و خانوادهٔ مقایسه‌شده

دامنهٔ پذیرش

پوستهٔ مستقل Windows 4.1.1 روی سیستم هدف runtime-tested است: اجرای مستقیم EXE، Taskbar/Tray، Minimize→Tray→Restore و single-instance پذیرفته شده‌اند. چهار روش WARP،GOOL،CFON/AT وTor نیز در browser/proxy scope دارای شواهد HTTPS قبلی هستند. VPN کل ویندوز، بازی UDP، leak capture و پایداری طولانی هنوز پذیرفته‌شده نیستند.

مجموعهٔ unit tests در ۲۰ سپتامبر ۲۰۲۶ دوباره اجرا شد: ۳۲ تست، صفر failure/error و یک skip موردانتظار. شواهد اصلی در Brain package قرار دارند.

Oblivion Desktop

WARP، Gool، Cfon/Psiphon و MASQUE؛ حالت پروکسی، System Proxy و TUN؛ tray، روشن/تیره، RTL، scanner و speed test در جدول رسمی پروژه.

محدودیت: کلاینت غیررسمی Cloudflare؛ کارکرد روی هر اپراتور تضمین نیست. Kill Switch در جدول رسمی بررسی‌شده هنوز علامت تکمیل نداشت.

تصمیم: سه روش WARP/GOOL/CFON، تم روشن/تیره، tray و اسکن مقایسه‌ای در Hub پیاده شد؛ MASQUE و TUN بدون آزمون واقعی به‌عنوان سالم عرضه نشدند.

https://github.com/bepass-org/oblivion-desktop

Oblivion Android / Aether

محدودیت: VPN permission و آزمون روی خود اندروید لازم است؛ نتیجهٔ Windows روی hotspot پذیرش Android نیست.

تصمیم: مرجع مقایسهٔ حالت کشور و تنظیمات؛ این انتشار مخصوص ویندوز است و APK تغییر داده نشد.

https://github.com/bepass-org/oblivion

Tor / Snowflake / WebTunnel / obfs4 / meek

خانواده‌های transport ضدسانسور؛ Snowflake از واسطه‌های موقت و WebTunnel از ظاهر HTTPS استفاده می‌کند.

محدودیت: WebTunnel و obfs4 پل واقعی لازم دارند. Chrome روی Tor حفاظت‌های Tor Browser رسمی را ندارد. سرعت و bootstrap به شبکه وابسته است.

تصمیم: Snowflake مستقل و import معتبر WebTunnel/obfs4 اضافه شد؛ پل خالی MISSING است. meek بدون پیکربندی قابل‌استفاده به‌صورت دکمهٔ آماده نمایش داده نشد.
